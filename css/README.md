# Стили интерфейса

`index.html` подключает файлы в таком порядке:

1. `style.css` — темы, общие элементы и ещё не выделенные части сайта.
2. `css/novel-grid.css` — общая геометрия карточек и сеток каталога, полок и созданных новелл.
3. `css/profile-library.css` — библиотека профиля: полки, поиск, карточки, список и пустые состояния.

Книжные каталоги и библиотека профиля выделены из общего файла. Карточка пользователя, настройки и остальное оформление остаются в `style.css`.

## Где менять библиотеку

В `profile-library.css` пять разделов: область библиотеки, навигация, инструменты, карточки, пустые состояния. Условия ширины экрана и состояния компонента находятся в том же разделе. Новые правила полок нужно менять здесь, а не добавлять переопределения в конец `style.css`.

Цвета берутся из общих переменных темы. Количество колонок рассчитывает `js/layout.js` по доступной области; CSS распределяет их ширину в пределах заданного шаблона, задаёт промежутки и оформление. Класс `.novels-grid` используется в каталоге, на страницах автора и создателя/переводчика, в созданных новеллах и на полках. `layout.js` записывает CSS-переменную `--novel-grid-template`; режим `.list-view` игнорирует её и сразу показывает одну полноширинную колонку. Положение полок задаёт `data-placement`, свёрнутое состояние — `is-compact`.

Все книжные сетки, включая страницы автора и создателя, используют общий диапазон 150–200 px. Минимум — две колонки, поэтому в очень узкой области карточки могут быть меньше 150 px. Число колонок зависит только от области, а не от числа книг. При достижении места для нового столбца карточки перераспределяются; верхняя граница 200 px не позволяет двум обложкам разрастаться. Если до нового столбца остаётся свободное место, общий блок колонок делит его поровну по краям. Неполный последний ряд начинается с первой колонки. Значения диапазона заданы один раз в `NOVEL_GRID_CARD_SIZE` в `js/layout.js`; CSS получает верхнюю границу через шаблон колонок. Интервалы, пропорции обложек, двухстрочные заголовки и размеры строк списка общие для всех пяти разделов; изменения этих правил вносятся в `novel-grid.css`.

Верхние полки всегда развёрнуты: значки, подписи, горизонтальная прокрутка. Кнопка и жесты сворачивания в этой планировке отключены, обычная вертикальная прокрутка страницы не перехватывается. Сохранённая ширина и свёрнутое состояние относятся к боковой планировке; переключение наверх их не изменяет.

Старые ограничения ширины с `!important` пока сохранены: это существующий контракт с `applyProfileShelfWidth`, который задаёт колонки непосредственно в элементе. Убирать его нужно одновременно со сменой этого механизма и проверкой перетаскивания разделителя.

## Проверка изменений

`npm run check` проверяет синтаксис JavaScript и наличие локальных CSS-файлов из `index.html`. `npm test` проверяет логику размеров, переключений и жестов. Визуальные изменения дополнительно проверяются в браузере: полки сверху/сбоку, свёрнутые/развёрнутые подписи, сетка/список, короткие/длинные названия, поиск без результатов.

При выделении модуля 06.11.2026 сравнивались старые и новые вычисленные стили и геометрия элементов в восьми компоновках шириной 390, 572, 900 и 1280 px. Исходная версия и отчёты сохранены в отдельной резервной копии за эту дату.

## Оформление и фильтры каталога

Общие радиусы компонентов заданы в начале style.css: 6 px для небольших элементов, 8 px для кнопок и обложек, 16 px для крупных поверхностей. Аватары сохраняют круглую форму. Палитра берётся из текущей темы.

Фильтры — один нативный dialog в index.html, а не копия формы. Браузер обеспечивает модальность, удержание фокуса и Escape. toggleFilters сохраняет прокрутку html/body и возвращает её при закрытии; блокировка прокрутки использует общее правило для открытых модальных диалогов и меню полок. Поле .catalog-filters-body прокручивается, заголовок и действия остаются видны.

Выбранные теги снимаются нажатием на плашку. Используются прежние функции обработки включения/исключения и общий вывод выбранных тегов; второй механизм фильтрации не создаётся.
